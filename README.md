## CineMancer

## DefrauderAI

<img src="https://capsule-render.vercel.app/api?type=slice&color=0:7B2FF7,100:101A40&height=95&section=header&text=DefrauderAI&fontSize=30&fontColor=050816&fontAlignY=48&desc=real-time%20risk%20scoring%20for%20banking%20transactions&descSize=12&descAlignY=76&rotate=13" width="100%"/>
